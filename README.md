# Dynamic Island for Windows (Java) 🏝️

Dynamic Island для Windows в стиле iOS, отображающий текущую музыку, статус сети, время и системные уведомления прямо вверху экрана по центру.

## Особенности
- **Динамический остров (Dynamic Island)**: Черная плашка капсульной формы сверху экрана без лишней прозрачности фона острова.
- **Интеграция с плеерами (Spotify, Яндекс.Музыка, Браузеры)**:
  - Слева отображается обложка текущего трека со скругленными углами.
  - Название трека белым шрифтом **Nunito-Bold** (с плавным marquee-скроллом при длинных названиях).
  - Справа анимированный эквалайзер из **6 тонких полосок**, цвет которых генерируется на основе градиента обложки трека.
- **Уведомления Windows**:
  - При получении уведомления проигрывается звук `ding.mp3`.
  - Динамический остров плавно расширяется с анимациями **slide** и **fade**.
  - Вместо обложки трека появляется иконка приложения и его название с текстом уведомления.
  - Через 4.5 секунды остров плавно возвращается в режим музыки или покоя.
- **Адаптивная яркость (Dynamic Theme)**:
  - Проверяет яркость обоев/экрана под левой и правой частью статус-бара.
  - Если фон светлый — иконки и текст плавно переходят в темную тему (`wifi5-8`, черный самолетик, темные часы).
  - Если фон темный — иконки и текст белые (`wifi1-4`, белый самолетик, белые часы).
  - Переключение происходит с быстрой и плавной fade-анимацией.
- **Статус-бар**:
  - Слева: Иконка самолетика и индикатор Wi-Fi (4 уровня сигнала: от отличного до отсутствия интернета).
  - Справа: Текущее время шрифтом **Nunito-Medium**.
- **Интерактивность**:
  - Правый клик по острову открывает меню: «Тестовое уведомление», «Сбросить позицию», «Выход».
  - Левой кнопкой мыши можно свободно перемещать остров по экрану.

## Сборка и запуск

Требуется: Java 21+.

```powershell
# Запуск через Gradle Wrapper:
.\gradlew.bat run

# Или сборка исполняемого JAR:
.\gradlew.bat jar
java -jar build/libs/dynamicisland.jar
```
